# 11 复检

> **接口**　输入：各章 `进度.md` 与 `*_错题本.html`　输出：本轮卷面 HTML、三态结果、状态回填
> **依赖**　05（四档状态与回填）、10（报告结构）、03（错题本数据契约）
> **不负责**　新题讲解（01/02）、无记录章节的冷启动取样（10）、折页（07）、产物路径与清理（`config.md`）
> **触发**　复检、第 N 次复检、查漏、结算

## 定位

复检是「按历史错题出闭卷卷」：从本章已有错题里选题，遮住解答让用户独立重做，做完自评三态，再回填。

与 10 的分界：10 的 B 入口针对**没有历史记录**的整章冷启动，取样按知识点覆盖；本模块针对**有错题记录**的定向回炉，选题按复发度与状态，不看知识点覆盖。

## 一轮的边界

- 一次只做一章。多章都欠账时先做错次最高的一章，其余排队，不合并成跨章卷。
- 卷内 6–8 题，闭卷 25–35 分钟。
- 第 N 次只收：上轮未通过的、上轮之后新增有错的、整题空白的。已「已掌握」的不再进卷。

## 选题

按下列优先级取，取满 6 题为止，上限 8 题：

1. 错次 `×N ≥ 2` 的题，按 N 降序；
2. 整题空白（状态「未开始」）的题；
3. 状态「未通过」「待复测」「进行中」的题，按最近一次出错日期倒序。

全章均为「已掌握」时不出卷，改按 10 的冷启动取样，只在基础篇结算与冲刺前各查一次。

## 卷面构成

| 原题状态 | 卷内形式 |
|---|---|
| `×N ≥ 2` | 原题，闭卷重做 |
| 整题空白 | 原题，闭卷首做 |
| `×1` 且非空白 | 同型变式，优先取错题本 `practice` 字段（`q` 与 `a`）；没有则新编并标「AI 补充题」 |

每题只保留：编号、病根标签、错次、题干、三步要点、答案、上次错因。剥掉分步引导、提示与分步问答。卷内按病根分组连排，卷首标注本次主查的病根。

## 病根

固定四条，用作卷内标签与回填依据：

| 病根 | 判据 |
|---|---|
| 记账失守 | 系数、常数、因子、幂次、括号、符号在书写中途丢失或错位 |
| 变限积分结构 | 被积函数含参数未先换元；积分号外因子未提出；上下限是函数未乘其导数 |
| 证明题假证明 | 循环论证、把特例等式当恒等式、论证链条不足 |
| 判据读错 | 导数阶与符号方向、可导与连续的关系、极限值记错、判据顺序颠倒 |

归不进这四条的标「其他」，不硬塞；同一题同时犯两条时记先出错的那条。

## 卷面交互

- 默认只显示题干；要点、答案、上次错因逐层展开，先答题后揭晓。
- 每题底部三态：独立过 / 提示过 / 未过。
- 顶部显示作答进度与剩余题数。
- 交互态写 `localStorage`，键含文件路径，不算学习记录。

## 通过标准

按题型分层判，不设整卷百分比：

| 题型 | 通过 |
|---|---|
| 选择、填空、单步计算 | 独立过。有一题未独立过，本轮即不解账 |
| 解答、证明、多步综合 | 独立过，或能正确说出第一步与所用方法 |

取舍口径是「基础题不丢分、难题有思路」。本轮通过则记结账；不通过出第 N+1 次，只收本轮未过与新增。

## 出卷

1. 读该章 `进度.md` 的错题索引，按选题规则定题单。题干与出处不手抄，交给生成器按题号从错题本取。
2. 写数据模块（`.mjs`，`export default [...]`）：每题给 `g`（病根）、`key`（原题号）、`no`（卷内序号）、`lv`、`xn`、`kind`（原题／变式）、三步要点、答案、上次错因。变式只标 `kind:'变式'`，生成器自动取该题 `practice.q`，没有则报错，转标原题或另编。
3. 运行 `assets/gen-recheck.mjs`：

   ```text
   node assets/gen-recheck.mjs dump  <错题本.html> [题号...]    先看题目数据
   node assets/gen-recheck.mjs build <错题本.html> <卷号N> <数据模块.mjs>
   ```

   卷面落 `<章目录>\复检\第N次复检.html`；KaTeX 由生成器从当章错题本原位抽取，页面完全自包含，可离线打开。样式与交互骨架在 `assets/recheck.css`、`assets/recheck.client.js`，改版式改这两处，不改单张卷面。
4. 首次出卷为第 1 次；已有第 N 次则出 N+1。生成器拒绝覆盖同名卷。

## 核对

出卷后先自己走一遍：题干与出处是否与错题本一致、每题的病根标得对不对、答案与「上次错在」是否互相印证、变式是否真换了形式而没换数字。四问有一问不对就重出，不交付。

## 回填

做完后按 05「复测与打卡回填」表写回该章 `进度.md`：

- 错题索引改状态与 `×N`；
- 「下次复测」删已过的条目，留下的补一行下次动作；
- 文末追加「复检」小节：第 N 次、日期、卷内题号、三态分布、未过题号与下一步。

结果不另开文件，也不改错题本 HTML 的数据。

## 去留

历次卷面长期保留，是掌握证据，不参与章末清理；清理豁免见 `config.md`「章末清理」。

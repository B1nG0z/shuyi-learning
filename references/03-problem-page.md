# 03 讲题页

> **接口**　输入：02 已判定 `mode` 的题、题目数据　输出：单文件 HTML、页面自查结果
> **依赖**　04（第 7 节问答区）、05（状态写回）
> **不负责**　错型判定（02）、页内提问交互与写回（04）、折页（07）
> **触发**　讲题、首讲、有错的题、看页面

## 何时用

**用**：批改后有错的题（按错型裁剪）、例题带做、知识点首讲、一题多解对比、阶段复习的解题回顾。
**不用**：全对的题、一句追问、条件确认、一句话提示、纯口算题；用户明确说「直接打字告诉我」时也从简。

判断标准：有错且值得留下修正记录，或需要完整讲解，就进 HTML；全对和一句话能说清的，不进。

## 一文件一章

- **一章一个文件**，从开学跟到章末，不在章内按课时或批次另建。文件落在本章章目录，目录与文件名见 `config.md`「产物清单」。
- 每次批改后有错的题才追加在 `PROBLEMS` 末尾，带 `date`（YYYY-MM-DD）；数组顺序就是时间顺序，不重排、不改写旧条目。
- 只有换章才新建文件。单文件超过约 60 题或 2 MB 时，才按「前半章／后半章」拆分，并在两个文件顶部互相注明。
- 题目内容要改（例如答案有误）时，只改该题对象，并在 `rev` 记一句修订说明，不删除重加。
- 离线可用，不依赖 CDN、不引用外部字体；浅色主题。视觉与本地学习站同一套：系统无衬线正文、白卡＋`#f6f8fa` 底、`#d8dee4` 细线、6px 圆角、绿色进度、等宽数字；令牌集中在模板 `<style>` 顶部，改色只改令牌。
- 顶栏左上角方块是返回「数一学习看板」的相对链接（`../../00_数学看板.html`），章目录层级固定为三档，换章不用改。
- 数学：模板已内嵌 KaTeX（含字体，断网可用）。公式必须渲染成可直接阅读的数学排版，不得把 LaTeX 源码展示给用户。行内 `$...$`，独占一行 `$$...$$`；JS 字符串里反斜杠写双份，如 `'$\\frac{1}{2}$'`。渲染失败、裸露源码、乱码反斜杠或红色报错公式均不得交付。

## 首页

- 标题写章节名与题数；一行统计：总题数 / 未开始 / 进行中 / 待复测 / 已掌握。
- 列表每题一行：编号、提交日期、题型名、来源、难度、考点标签、状态标签、进度条与百分比；未掌握的行尾带「一键掌握」小按钮。
- 列表按数组顺序（提交时间正序）排列，不按状态或难度重排；搜索与过滤只做筛选，不改顺序。
- 支持关键词搜索与按状态过滤（全部 / 未完成 / 待复测 / 已掌握）。
- 工具栏有「复制进度」：每行输出 `T01｜题型名｜已掌握 80%｜2026-11-07｜考点/标签`，粘回对话即可写进 `进度.md`。
- 工具栏有「复制卡表」：每行输出 `T01｜题型名｜一句错因｜待复测｜日期`，章末直接用来筛折页卡。
- 页面状态由本机交互推导，不手填：0 步未展开＝未开始；有「看了才懂」＝待复测；各步全部「独立想到」＝已掌握；其余＝进行中。正式判定以 `进度.md` 为准（见 05）。

## 详情页按错型裁剪

字段能省就省，页面会自动隐藏缺的区块，编号保持连续。三种基本形状：

| 错型 | mode | 写什么 | 省略 |
|---|---|---|---|
| 计算／笔误 | `fix` | 题目、2 步（错在哪 / 正确一笔）、完整解答（只写修正链）、复盘一句 | 提示、同型 |
| 方法／条件 | `method` | 题目、2–3 步、1–2 级提示、完整解答、复盘 | 同型可省 |
| 概念／没思路 | `full` | 六段全套 | 无 |

1. **题目**：题干原样；关键条件包成可点选的条件芯片，点芯片在题干中高亮对应位置，点题干标记可反选。AI 自编题在来源处标「AI 补充题」。
2. **本题拆解**：`fix` 用 2 步，`method`/`full` 用 2–3 步。每一步**先只露引导问题**，点开才显示内容；展开后可自评「我独立想到 / 看了才懂」。三步时标题写「三步拆解」，其余写「本题拆解」。
3. **逐级提示**：仅 `method`/`full`；`hints` 为空时整段不显示。用满后提示「可以看完整解答了」。
4. **完整解答**：默认锁定，需主动点击解锁；`solution` 为空时整段不显示。文风按 SKILL.md「输出标准」，不另立一套。
5. **复盘**：条件—工具—目标 三列对照表，加「识别特征 / 可迁移判据 / 易错」；`review` 为空时整段不显示。
6. **同型一练**：1 道，答案折叠；`practice` 为空时整段不显示。
7. **问答历史**：结构与写回规则见 04；无记录时整段不显示。

顶部固定条：返回列表、第 x / n 题、本题进度、上一题/下一题。路由用 `#/p/<id>`，刷新与浏览器后退都能回到原位。

## 数据结构

题目的全部内容写在文件里的 `PROBLEMS` 数组中，一道题一个对象：`id / no / date / mode / title / source / err / tags / level / stem / chips / steps / hints / solution / review / practice / rev`。`mode` 取 `fix` / `method` / `full`；`hints`、`solution`、`review`、`practice` 都可省略，页面会自动隐藏对应区块；`steps` 至少 1 步。`err` 是可选的一句错因，只有错题才写，「复制卡表」会带出来。样式与交互代码不动，只改 `SET` 与 `PROBLEMS`。`SET.key` 可留空，留空时用文件路径区分，不会串档。模板只含 1 道完整示例，正式使用时应整批替换，别把示例留在正式文件里。

## 交互与记录

- 折叠区默认收起，不预先渲染成可见文本——一眼看完就没有交互意义。
- 展开状态、自评、提示次数、是否解锁写入 localStorage（键 `shuyi.set.<章key>|<文件路径>`），按题 id 分开存；刷新、退出、再进入都不丢。带文件路径是为了让同一目录下的多章互不串档。
- **localStorage 只承担页面交互态，不是学习记录**：换设备、清缓存就没了。真正的记录写在章目录的 `进度.md`，每轮由 AI 写回；页面状态只作当次依据。
- 每轮收口：你点「复制进度」粘回对话，AI 把新增题、错次和状态变化写进 `进度.md`；页面文件本身不改状态。
- 题目进度 = （已展开步数 + 已自评步数）/（步数 × 2），不伪造完成度。
- 自评为「看了才懂」的步骤，该题在首页标为**待复测**，不记为已掌握——与掌握证据规则一致。
- 用户在页面上完成的步骤，等价于课堂上的口头回答，属于「已观察到」，不单独作为掌握依据。
- 每道题各有「重置本题」；重置只清当前题，不清整批。
- 每道题有「一键掌握」（详情页头与底部各一处，列表行尾另有一处）：一次把本题所有步骤记为「已展开」＋「我独立想到」，进度满格、状态转「已掌握」，不弹确认。它就是逐步自评的批量写法，只写页面交互态，不提高 05 的掌握证据等级；已掌握时按钮置灰显示「已掌握」，反悔用「重置本题」。

## 模板使用

- 骨架复制 `assets/explain-template.html`，**不必通读**：只需替换 `const SET = {…}` 与 `const PROBLEMS = [ … ];` 两段（从 `const PROBLEMS = [` 到其后第一个行首 `];`），其余原样保留。这样一次讲题只需读本文件与数据段。
- 模板约 685 KB（已内嵌 KaTeX 与字体，断网可用）。视觉层与站点对齐，勿改回暖纸＋藏青旧配色。
- 技能目录里如存在 `explain-template.bak-*.html`，一律视为旧备份，**不得复制使用**。

## 章末打印

只有用户说「打印／出折页／章末整理」时才做，章内不生成任何 PDF。筛卡、两册规则、版式、验收与章末清理全部见 07。

## 交付前自查

- [ ] 错题本 HTML 写在 `config.md` 指定的站点章目录，未落桌面根目录、技能目录；站内地址能直接打开。折页另有工作区落点，不写进站点（见 `config.md`「折页落盘规则」）；章末清理后站点章目录的生成物只剩本 HTML 与 `进度.md`（见 `config.md`「章末清理」）。
- [ ] 单文件、断网可开、无外链；只收有错或需完整讲解的题，全对的不进；编号连续、id 不重复；主页统计与状态一致，点卡片能进、返回保留进度，上一题/下一题可翻。
- [ ] 拆解步骤默认折叠；有提示时逐级解锁且级数可见；有解答时默认锁定。
- [ ] 缺省区块没有留下空白标题或编号断档（`fix` 模式应只剩 4 段：题目／拆解／解答／问答）。
- [ ] 完整解答是答卷文风：无标签、无旁白、无序号堆砌，结论自然收束。
- [ ] 条件芯片能高亮题干、题干标记能反选；刷新后展开/自评/提示/解锁仍在，重置本题可用。
- [ ] 「一键掌握」三处入口（详情页头、详情页底、列表行尾）都能点；点后本题进度 100%、状态「已掌握」，刷新后保持；已掌握时按钮置灰，打印时该按钮不出现。
- [ ] 提问入口齐全：悬浮按钮、步骤「问」、首页「待问 N」、「复制待问」。
- [ ] 「复制进度」与「复制卡表」输出完整，可直接写 `进度.md` 或筛折页卡。
- [ ] 公式已由 KaTeX 渲染，无裸露 `$`、`\frac`、`\begin`，也没有红色报错公式。
- [ ] 正文与标题均为系统无衬线，浅色主题；配色、圆角、进度条与本地学习站一致；打印时折叠区自动展开。
- [ ] 来源已标注；AI 自编题已标「AI 补充题」。
- [ ] 问答区另按 04 的四项自查执行。

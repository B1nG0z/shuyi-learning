# 04 页内问答

> **接口**　输入：学生在页面上记录的问题、AI 的回答　输出：追加进 HTML 的 `QA_LOG`、第 7 节问答历史
> **依赖**　03（页面骨架与 localStorage）
> **不负责**　页面列表与题目字段（03）、进度状态（05）
> **触发**　页内提问、回答写回、问答历史、复制待问

## 离线前提

页面是离线单文件，**不能调用模型**，所以提问做成「就地记录 + 一键复制」，不是即时回答。这一点必须在界面上写明，不得暗示页面会自己回答问题。

## 提问入口

- 每道题有一份独立的提问清单，每条带位置标签：题目 / 第一步…第三步 / 提示 / 完整解答 / 复盘 / 同型一练。
- 每个步骤标题右侧有「问」按钮，点开提问框时位置已预设为该步，不用手动选。
- 右下角悬浮按钮显示本题待问条数；首页列表对应题目挂「待问 N」标记，工具栏出现「复制待问 N」可一次复制全部。
- 提问文本、位置、已解决标记与草稿都随题目状态一起存 `localStorage`，刷新不丢。
- 「已解决」用手动勾选（点文本划线），只影响待问计数，不自动判断。
- 复制格式固定，便于回对话后一眼读懂：

```
【提问】T02 · 看到 f 与 f′ 的线性组合，先倒着找原函数
1. [第二步 · 目标锚定] 为什么 2xf + x²f′ 能看成 (x²f)′？
2. [完整解答] 罗尔定理的端点值必须单独验证吗？
```

交付时在对话里补一句：页内可随手记问题，做完点「复制全部」；进度点「复制进度」，我写进 `进度.md`。

## 写回 QA_LOG

提问在浏览器里，答案要落到文件里，否则换个设备就没了。规则：**答完一轮，把问答追加进 HTML 的 `QA_LOG` 数组**，页面据此渲染每道题的第 7 节「问答历史」。

```js
{ pid:'p2', loc:'第二步 · 目标锚定', d:'2026-11-07',
  q:'这类构造辅助函数的题，有没有通用套路？',
  a:'<div class="lead">只有一条：把结论式读成某个 F′，再解出 F。</div>' +
    '<div class="k"><i>01</i><div><p><b>先把结论式移项</b>凑成 $F(1)-F(0)=0$ 的形状。</p></div></div>' }
```

- `pid` 对应题目 id；`loc` 照抄提问时的位置标签；`a` 写下面「四件套」结构（旧条目用 `p` / `ul` 也仍能显示）。
- **`q` 必须与学生原话逐字一致**——页面靠 `pid + q` 匹配，改写一个字就显示不成「已回答」。
- 追加在数组末尾，保持时间顺序；同一问题追问时新增一条，不要覆盖旧答。
- 写回后，该问题自动从「待问」计数里消失，并在面板里标「已回答」；第七节按时间列出全部问答。
- 若学生删了本地问题，`QA_LOG` 里的记录仍保留——文件就是档案，这比浏览器存储可靠。
- 每轮回答后在对话里说明写回了哪几题，例如「已把 T02 的两条写进问答历史」。

## 问答正文四件套

第 7 节是全页唯一按「定稿版式」排的地方：白卡、1.5px 墨线分层、等宽编号栏。全页已是同一套系统无衬线，问答区靠墨线与编号区分层级，不再靠换字体——讲题要读，问答要扫。

正文按四件套写，**不要写成连续段落**：

```html
<div class="lead">一句结论：能/不能，以及答案落在哪。</div>
<div class="k"><i>01</i><div><p><b>这一小步干什么</b>做法一到两行，公式用 $...$。</p></div></div>
<div class="k"><i>02</i><div><p><b>下一步</b>…</p></div></div>
<div class="warn"><b>易错</b>最容易写错的那一处，一句话。</div>
```

- `.lead` 只放一句结论，≤40 字；不铺垫、不写「下面分四步说」。
- `.k` 2–4 条，编号 `01` 起；`<b>` 是小标题（≤10 字），其后一到两行说明。
- 需要展示推导时，公式单独成段用 `$$...$$`，不要塞在句子中间被断行。
- `.warn` 可选一条，写「哪里最容易错」，不重复正文。
- 旧条目保持原样即可，段首加粗会自动升成小节标题，不必回改。

学生明确要求「只在对话里答、不要改文件」时，跳过写回。

## 交付自查

- [ ] 提问内容含题号、题型与位置标签；界面明写「离线暂存，回对话一次发我」，不暗示页面能回答。
- [ ] 回答已追加进 `QA_LOG`，`q` 与学生原话逐字一致，第七节「问答历史」能显示。
- [ ] 问答正文是 `.lead` + `.k` + `.warn` 四件套，没有连续长段；公式单独成段。
- [ ] 已在对话里说明写回了哪几题。

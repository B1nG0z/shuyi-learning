## 选型

本机装有两套，按「谁看」判断：

| 判据 | 工具 | 理由 |
|---|---|---|
| 用户要在屏幕上看、要拖参数、要看几何关系 | **GeoGebra Calculator Suite**（默认） | 输入栏直吃命令；滑杆实时联动；覆盖数一函数类绝大多数场景 |
| 需要我直接交出图片文件（错题本、折页、报告） | Mathematica 内核 | GeoGebra 无导出接口，只能人工截图 |
| 需要高精度数值或复杂符号推导验证 | Mathematica 内核 | GeoGebra 的 CAS 深度有限 |

一句话：**给人看，交 GeoGebra 代码；给我出图，调 Mathematica。**
两套都用不上时，才退回文字描述或 HTML/CSS 示意图。

## GeoGebra 怎么写

输出形态：可直接粘进输入栏的命令，一行一个对象，按依赖顺序排（先定义，再求导、求交、求极值）。
命令用英文原名；若界面未识别，用输入栏自动补全挑对应项。

| 要什么 | 命令 |
|---|---|
| 函数 | `f(x) = x^3 - 3x + 1` |
| 分段函数 | `f(x) = If(x < 0, x^2, 2x - 1)` |
| 参数滑杆 | `a = Slider(-3, 3, 0.1)` 再接 `f(x) = a x^2` |
| 导数 | `Derivative(f)` 或 `f'(x)` |
| 极值与拐点 | `Extremum(f)`、`InflectionPoint(f)` |
| 零点 | `Root(f)` 或 `Intersect(f, xAxis)` |
| 渐近线 | `Asymptote(f)` |
| 定积分 | `Integral(f, 1, 3)` |
| 参数曲线 | `Curve(cos(t), sin(2t), t, 0, 2π)` |
| 极坐标曲线 | `Curve((1 + cos(t)) cos(t), (1 + cos(t)) sin(t), t, 0, 2π)` |
| 隐函数 | `x^2 + y^2 = 4`（等式直接写） |
| 不等式区域 | `y > x^2 - 1` |
| 曲面 | `Surface(u cos(v), u sin(v), u^2, u, 0, 2, v, 0, 2π)`，需切到 3D 视图 |

纪律：

- 一次不超过 6 条；每条后跟一句「看什么」，不超过 15 字。
- 不写「已为你画出」——我没有执行 GeoGebra 的能力，交的是代码，不是结果。
- 收尾请用户把图发回，我按图讲；用户不发，就不谈图上的细节。

## Mathematica 备选

需要落盘图片或高精度验证时：

```
wolframscript -code 'Export["路径.png", Plot[Sin[x]/x, {x, -10, 10}], ImageSize -> 800]'
```

导出后读图再讲。单次调用是独立会话，变量不跨轮保留；多步计算写进同一个 `.wls`。

## 何时不画

图不替代证明与条件检查，不能据图断言一般结论。与当前问题无关的图不画。

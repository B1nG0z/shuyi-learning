# 07 折页

> **接口**　输入：章 HTML 的 `PROBLEMS`、`进度.md` 的筛卡结果　输出：两份折页 PDF（HTML 源稿为渲染底稿，章末清理时删）
> **依赖**　08（排版规格）、05（记录写回）
> **不负责**　卡片内容从哪来（03/05）、字体字号与毫米（08）
> **触发**　章末整理、打印、出折页、生成 PDF

## 触发

只在章末或用户明确要求打印时生成，章内不产折页。折页内容从章 HTML 的数据中筛卡，不另起一份错题记录。数据源在站点章目录的 HTML，成品写工作区折页工作目录，两处不混（路径见 `config.md`「产物清单」）。

## 两册分工

| | 笔记折页：认型 | 错题折页：认病根 |
|---|---|---|
| 收录来源 | 做题后仍未独立通过、且能写出钥匙的题 | 卷面真实写错、算错、选错、半对、空白 |
| 主体 | 卡头 → 钥匙 → 三步 → 坑 | 左列病根/卷面原样 → 右列可执行动作 |
| 数量 | 每套 CARDS_PER_SET 张主卡，每栏 CARDS_PER_PANEL 张 | 每套 ERRORS_PER_SET 条，内页一 ERRORS_INNER_1 条、内页二 ERRORS_INNER_2 条 |
| 功能 | 随手认型、调用最短解法 | 对照当时错法，立即修正下一笔 |
| 不收录 | 无钥匙、已独立通过、同法重复题、无出处题 | 假设性错误、无卷面证据、只写「粗心」 |

两册分开生成，不混写。每张卡只表达一件事；同一方法的题只建一张卡，其余题号放入「同型」。题号、页码或来源无法确认时不建卡。

## 容量参数（唯一数值源）

下面的数值是本技能与 05 的**唯一出处**。其余位置一律引用名称，不再重复写数字；要调容量只改这一处。

```yaml
CARDS_PER_SET: 15      # 每套笔记主卡数（已验证容量）
CARDS_PER_PANEL: 5     # 每栏主卡数 → 封面之后三个阅读面各 5 张
ERRORS_PER_SET: 18     # 每套错题条目数（已验证容量）
ERRORS_INNER_1: 11     # 错题折页内页一条数
ERRORS_INNER_2: 7      # 错题折页内页二条数
```

超过容量时另起一套折页并保持编号连续，不压缩字号、不删关键条件。

## 笔记折页内容

数据层沿用已确认的五格：`题—钥匙—三步—同型—坑`，不得删除关键条件。折页展示层按 A5 密度压缩：

```text
[编号] 题型名                          [来源] [Pxx]
钥匙  一句判据；读完后必须明显降低题目难度
三步  ①[标签] 公式
      ②[标签] 公式
      ③[标签] 公式
同型  仅在存在同法题号时列出；无则省略
坑    ①具体错误动作
      ②第二项具体错误动作，可省略
```

### 笔记卡规则

1. **卡头**：黑体题型名＋可确认出处＋印刷页码签；题号必须来自实际资料。原五格中的「题」压缩为卡头里的题型名与触发信息，不抄完整题干。
2. **钥匙**：黑体常规，不超过 20 字；必须能直接指出切入点。读完仍不知道第一步，就不入卡。
3. **三步**：最多三步，每步一行，只放公式；标签不超过 4 字，序号计入标签宽度。三步走不完说明类型没抓住，应回到题干重认。
4. **同型**：仅写题号。能在已有卡下合并的题不再新开卡。
5. **坑**：最多两条，使用仿宋，写具体错误动作或错误写法；不写「粗心」「注意」等空泛警告。
6. **无「例」栏**：不在折页重复例题；需要展开时回详细笔记或教材。

折页之间保留「易混对比」「法则三句话」等辅助块，只放能够帮助当场识别题型的对照，不扩写背景知识。每个内容点仍应能回到具体题或教材页。

## 错题折页内容

错题条目采用左右两列，不写长篇完整解答：

```text
[编号] [来源/题号/×N]                          [Pxx]
病根（仿宋）                              动作（黑体）
照录卷面当时写错的那一笔                  → 下一笔应当执行的修正
```

- **病根**：保留卷面原样，优先使用截图或影像嵌入；不改写、不润色，保留划改痕迹。空题单独标为空题，使用虚线框和灰编号，不与真实错题混计。
- **原样图**：存折页工作目录的 `img\E01.png`（路径见 `config.md`「产物清单」），按卡号命名，只在出折页期间有效；章末清理时随 `img\` 整个目录删除（影像已嵌入 PDF）。裁切、旋转、拼版预览等中间图放同一目录的 `.tmp\`，一并删除。
- **动作**：黑体，必须以 `→` 起头，写成可直接执行的一笔，例如 `→ 先写 f'(x0)=0，再判 f''(x0)`。
- **错次**：首判错误后即使改对仍记作错；重复错误在来源处标 `×N`。
- **粗心**：只保留题号，不设独立条目。病根必须落到具体动作，不能只写「粗心」。
- **不完整解答**：折页只负责唤起修正动作；详细证明、完整替代解法保存在题目页中。

## 数据卡字段

实际数据存放在章 HTML 的 `PROBLEMS` 中；出折页时按下面的字段筛卡，**不另写一份卡片文件**。本文件只定义字段骨架；收什么、不收什么以及展示规则，以本文件上文「两册分工」「笔记卡规则」「错题折页内容」为准。

### 笔记卡

```markdown
### T[编号]｜[题型名]
- 出处：[资料/题号]
- 页码签：[Pxx，必须为教材印刷页]
- 题：[只保留触发句]
- 钥匙：[≤20 字，能明显降低题目难度]
- 三步：
  1. [≤4字标签] [只写公式]
  2. [≤4字标签] [只写公式]
  3. [≤4字标签] [只写公式]
- 同型：[仅题号；无则省略]
- 坑：[具体错误动作；最多两条]
```

五个字段缺一不可。

### 错题卡

```markdown
### E[编号]｜[来源/题号/×N]
- 页码签：[Pxx，必须为教材印刷页]
- 错因：[一句具体的人话]
- 题型：[触发特征或考点]
- 原样：[卷面错误影像或忠实记录；不得润色]
- 应写成：[完整正确链]
- 机关：[一句可迁移判据]
- 同型：[关联题号或卡号]
- 复测动作：[下次做该小节时可执行的口答/补步/变式]
```

## 四个版面

### 笔记折页

| 面 | 内容 |
|---|---|
| 封面 | 章节题目＋总钥匙一句＋「怎么用」3 条＋N 型索引（编号/型名/页）＋「四件怎么用」＋「三步走不完回头看哪」 |
| 内页一 | 前 CARDS_PER_PANEL 张卡；栏底放「易混对比」块 |
| 内页二 | 中间 CARDS_PER_PANEL 张卡；栏底放「法则三句话」 |
| 封底 | 末 CARDS_PER_PANEL 张卡＋通过标准＋编号打卡格 |

通过标准可写为「只看题干，能先报题型名，再说出钥匙，并在 60 秒内走完三步；只说答案不算过」。每个编号打卡格用于记录复测结果，空白处只打钩或记日期，不写演算。

### 错题折页

| 面 | 内容 |
|---|---|
| 封面 | 大标题＋说明段＋「怎么用」3 条＋六族条数表＋「不收」声明 |
| 内页一 | 病根族一至族三，共 ERRORS_INNER_1 条；放「三档条件」和「落笔前三问」 |
| 内页二 | 病根族四至族六，共 ERRORS_INNER_2 条；放「六族各留一个动作」和「四条判据公式」 |
| 封底 | 四批复测打卡表＋逐族打卡格＋重测口径＋下一章＋三册怎么配＋本轮记录空表 |

以上 CARDS_PER_SET 与 ERRORS_PER_SET 是已验证的折页容量。实际合格内容不足时，用真实课程要点、错因对照或复测清单补块，不伪造卡片；超过容量时另起一套折页，不压缩字号或删掉关键条件。

## 生成链路

0. 读 `进度.md` 筛题：笔记卡取「待复测」中拿得出钥匙的题，错题卡取卷面真错与空题。
1. 到章 HTML 的 `PROBLEMS` 取原题，核对题型、出处、印刷页、钥匙和三步；内容核验完成后再进入拼版。
2. 用 HTML 建四栏页面，版面按页面 1 `[封底 | 封面]`、页面 2 `[内页一 | 内页二]` 排列。打印时的短边翻转保证折后阅读顺序正确。
3. 数学公式优先用本地 KaTeX：可以先用 `assets/explain-template.html` 里内嵌的那一份（CSS 与主库各抽一行即可，`gen-recheck.mjs` 就是这么做的），再考虑运行环境里已装的 KaTeX；都没有时改用 HTML/CSS 排线性公式，并在交付说明里注明未用 KaTeX。含 LaTeX 的字符串使用原始字符串或正确的模板字符串，避免 `\xi`、`\Delta` 引发转义错误。
4. HTML 中只对数学定界区间处理 `<` 转义，不能全局替换而破坏标签。
5. 用 Chrome/Chromium headless `--print-to-pdf --no-pdf-header-footer` 输出，关闭浏览器页眉页脚。命令行里的路径必须是绝对路径：`config.md` 写的是相对路径时，先按工作区解析成绝对路径再传。
6. 每册先写 HTML 源稿再渲染 PDF：交付物只有 PDF，HTML 是可改的底稿。输出目录与文件名按 `config.md`「产物清单」，只写工作区折页工作目录，不写站点章目录、不写 Markdown。不得手改 PDF。中间截图与预览图放折页工作目录的 `.tmp\`。
7. 出完折页，把实收卡数与未入册题号写回 `进度.md`（格式见 05）。
8. 章末清理：按 `config.md`「章末清理」删源稿、`img\`、`.tmp\` 与其他生成类中间文件，只留两份 PDF；站点章目录的生成物只留错题本 HTML 与 `进度.md`，讲义与习题 PDF 等资料不动。

## 交付验收

按优先级分三档：**P0 任一不过即不得交付**；P1 影响可用性与可读性；P2 在交付前自查。

### P0 — 硬失败项

- [ ] PDF 正好 2 页、297×210 mm；第 1 面 `[封底 | 封面]`，第 2 面 `[内页一 | 内页二]`。
- [ ] 四栏 `maxY ≤ 573 pt`；正文不超过 202 mm，关键内容位于 193 mm 安全区。
- [ ] 卡头、钥匙、三步、同型、坑字段完整；钥匙 ≤20 字，三步 ≤3，坑 ≤2；错题病根保留原样，动作以 `→` 起头。
- [ ] PDF 文字层和图像中均无 `$`、`\dfrac`、`\begin` 等 TeX 源码泄漏。
- [ ] 数学条件、答案、等号点、方向与结论复核正确。

### P1 — 容量与版式

- [ ] 栏宽、页边距、中缝符合 08；文字不压中缝，底部折法小字不压正文。
- [ ] 笔记每栏 CARDS_PER_PANEL 张；错题内页一 ERRORS_INNER_1 条、内页二 ERRORS_INNER_2 条；空题、真错与 `×N` 计数一致。
- [ ] 宋体／黑体／仿宋三套语义与字号层级符合 08，黑体切换后回调 0.3–0.5 pt，全页无颜色依赖。
- [ ] 两份 PDF 都落在工作区折页工作目录、命名符合 `config.md`；站点章目录内无 `*折页*` 文件。
- [ ] 章末清理已完成：折页工作目录只剩两份 PDF；站点章目录的生成物只剩错题本 HTML 与 `进度.md`，资料 PDF 未被误删（清单见 `config.md`「章末清理」）。
- [ ] `\dfrac` 每卡不超过一个，含分式的行高足够。

### P2 — 细节自查

- [ ] 转成灰度逐页查看，两册仍可凭字形、字重、底纹和线条分辨。
- [ ] 中文引号统一为「」；题号、页码签、目录和打卡格编号连续。
- [ ] 无越界、断卡、孤行标题、叠字、空白半页或覆盖中缝。

只有实际生成并完成上述检查后，才能把 PDF 作为交付物链接。检查失败时先修正 HTML/CSS 或数据，再重新渲染；P0 项失败时不得以「已标注问题」的方式交付。

## 维护

错题折页只新增卷面真错和空题；笔记折页只新增「尚未独立通过且拿得出钥匙」的新题型。同法题只补入「同型」题号，不重复建卡。新增卡按教材印刷页签归位；若当前折页容量已满，另起一套并保持编号与目录连续。更新时维护数据与模板，重新生成同名 PDF，避免保留多个顺序不同却都声称最新的版本。

# 02 批改与诊断

> **接口**　输入：题目、作答、手写过程、错题照片　输出：对错判定、错型 `mode`、证据标签、最小补救
> **依赖**　03（mode 如何呈现）、05（状态写回）
> **不负责**　页面结构与字段（03）、折页版式（07）
> **触发**　批改、看过程、错题照片、卡住、没思路

## 批改顺序

1. **核对**：按题目要求逐步验算，找**第一个影响结果的错误**，不是第一个小瑕疵。全对就是全对，不为「有产出」硬找问题。
2. **分流**：按错型定 `mode`，只判不画。
3. **入册**：只有有错的题才追加进本章 HTML（对应段见 03），`err` 写一句错因；全对的不写。学生只要一句结论或明确要求不落文件时，只回诊断，不建 HTML、不写进度。

### 四档判定

| 判定 | mode | 后续 |
|---|---|---|
| 全对 | — | 只在对话回「全对」，不落文件；旧错题复测全对，改 `进度.md` 状态为「已掌握」 |
| 计算／笔误 | `fix` | 按 03 的 `fix` 形状写 |
| 方法／条件错 | `method` | 按 03 的 `method` 形状写 |
| 概念错／完全没思路 | `full` | 按 03 的 `full` 形状写 |

`fix`／`method`／`full` 是 02 与 03 之间的唯一接口值；本文件只判定，不排页面。

## 可靠转录

分别列出：可确认的题目原文、学生手写过程或旁注、教师课程/教材中已有的方法、AI 的解释或推断。诊断与讲解优先衔接教师课程和教材学过的知识；不假定看过不可访问的课程内容。重点识别修改、划掉、标记处，已完成部分和最可能的卡点。

上下标、正负号、根号范围、分数结构、积分或求和上下限、矩阵元素等关键符号不清时，不自行补全。指出具体位置，请学生补拍、裁剪或用文字确认。局部模糊不影响当前判断时，可先说明假设并继续可验证部分。

## 形成诊断

先找「最后一个可以确认正确的步骤」，再比较该步到目标之间缺少什么。诊断可含多个原因，但区分主要与次要，并为每项引用可见证据：

- 前置知识缺失或概念误解；
- 定义、公式或定理条件判断错误；
- 无法识别考点或建立切入；
- 方法选择不当或多种方法混淆；
- 有方向但推理衔接中断；
- 公式运用、代数或计算错误；
- 论证不严谨、步骤低效；
- 多知识点无法拆解。

信息不足时用「初步判断」，并提出一个最能区分候选原因的问题，避免连续盘问。

## 最小有效辅导

- **有过程且卡在某一步**：验证此前步骤，指出最后正确位置和具体卡点，从该处续接；只有卡点确由知识缺口造成，才插入最小必要讲解。
- **完全没有思路**：中高难度题按三桥回溯（细则见 01）；卡住时优先提示「从目标反推需要什么」「这个已知条件还能推出什么」，逐步加提示，不越过思考过程。完整解答后复盘条件、工具与目标的逻辑链，判断卡点在条件挖掘、目标识别还是搭桥工具选择。非中高难度题仍给可执行的第一步，不强行套完整流程。
- **有自己的分析或计划**：分别标注正确观察、暂时无效尝试和错误假设；保留数学上可行的思路并在其基础上修正；非常规方法成立时说明理由、适用范围和效率取舍。
- **只有局部计算或推导错误**：直接定位原式、错误变换和正确变换，说明如何预防，不扩写成整章复习。
- **概念或方法混淆**：用条件、题目特征和目标对比相似方法，再给一个短例或反例建立判断规则。
- **会做但不严谨或低效**：保留正确路线，优化书写和顺序；指出缺少的条件、论证或可省去的重复计算。

## 提示控制

默认先给足以推进的一步并等待反馈。以下情况可直接完整讲解：学生明确要求；考试复盘或时间紧；已多次尝试；继续追问不会产生有用诊断信息。不为维持「互动」而隐藏学生当前必需的信息。

## 证据标签与闭环

单次表现只产证据标签，不直接升级状态；状态机与掌握判定见 05。

- **本题独立做对**：独立作答且关键过程正确；
- **带做完成／需提示**：答案正确但依赖提示或示范；
- **未通过**：关键步骤错误或未完成。

完成后按题目价值选择性记录：考点、原始卡点、主要与次要原因、关键突破、规范解法及条件、同类题识别规则、需补的前置知识和一到两道针对性练习。完整内容写进 HTML 该题的复盘段；`进度.md` 的错题索引只留题号、一句错因、错次与状态，不重复抄写。

偶发计算错误简记即可；概念误解、典型思路障碍或重复出现的问题应深入记录。相同问题跨多题出现时，标为候选系统性薄弱点，并在后续独立题或变式中验证。

# 05 进度与状态

> **接口**　输入：本轮作答证据、复测结果、折页实收数　输出：更新后的 `进度.md`、章级 `掌握画像.md`
> **依赖**　无（只读写记录文件）
> **不负责**　计划怎么排（06）、折页字段与容量（07）、页面 localStorage（03）
> **触发**　读写进度、掌握判定、掌握画像、交接、复测、折页记录

## 唯一事实源

- 每章一个 `进度.md`，与章 HTML 同级，位置见 `config.md`「产物清单」；跨对话只认这份文件。不再用独立进度板或其他进度文件。
- 章目录没有就按 `config.md` 建，之后每轮先读、结束写回。
- HTML 的 `localStorage` 只存页面交互态，不算学习记录；换设备、清缓存就没了。
- 不声称能访问其他空间、对话或不可见历史；缺少可核实进度时，说明不知道上次学到哪，请学生给出最后条目或先做一道短题定位。

## 模板

```markdown
# 第 X 章｜进度

## 学到哪
- 课程/课时：
- 教材页：
- 下次起点：

## 错题索引
只记批改后有错的题；全对的不进表。
| 题号 | 错因（一句） | 错次 | 状态 |
|---|---|---|---|
| T03 | 辅助函数没构造出来 | ×2 | 待复测 |

状态只用：未开始 / 进行中 / 待复测 / 已掌握。

## 下次复测
- T03：只看题干，60 秒内说出构造思路
- T07：补做变式一题

## 折页
- 本轮：笔记折页 / 错题折页（文件名、页数）
- 笔记卡：实收 x 张（上限 CARDS_PER_SET，每栏 CARDS_PER_PANEL）
- 错题：真错 x 条、空题 x 条（上限 ERRORS_PER_SET）
- 未入册：题号 + 原因（无钥匙／已独立通过／同法重复／无出处）
```

## 四档状态机

| 状态 | 含义 | 进入条件 |
|---|---|---|
| 未开始 | 没有作答 | 只看了题或讲义 |
| 进行中 | 有尝试但未独立通过 | 看解析后完成、未完成、提示后仍错 |
| 待复测 | 曾独立做对，或看过才懂 | 独立做对但未过变式；页面自评「看了才懂」；提示后完成 |
| 已掌握 | 稳定通过 | 独立作答且关键过程正确，并经无提示的同类或小变式检验；隔日再抽一次确认 |

- 状态只用这四档，不写百分比，不写虚假的精确评分。
- 一次对错不作掌握判定；掌握须综合概念解释、条件判断、方法选择、独立解题与变式迁移。
- 旧错题复测全对，才把状态改为「已掌握」；同一题重复错只把 `×N` 加一，不新增行。
- 掌握证据不足时留在「进行中」或「待复测」，不跳级。

## 错题索引维护

- 只有有错的题才补一行；全对的新题不建行。
- 同一题重复错，`×N` 加一，不新增行。
- 错因写一句具体的人话，不写「粗心」；找不到具体动作时留「待确认」。
- 章末生成折页时，从这张表筛「待复测」与「已掌握」，再到 HTML 里取原题（见 07）。

## 复测与打卡回填

纸面打卡格只是打印时的采集面，不是账本；结果必须回填 `进度.md`。

| 打卡格写的结果 | 回填到 md 的状态 |
|---|---|
| 独立完成 | 已掌握（隔日再抽一次确认） |
| 提示后完成 | 待复测 |
| 看解析后完成 | 进行中 |
| 未完成 | 进行中 |

手写只落日期、结果和错次 `×N`。复测时遮住钥匙、三步和错题动作进行回忆；演算在草稿纸上完成，不写进折页。拍回给 AI，由 AI 写进 `进度.md`。

需要留存卡点文字时，在「下次复测」加一行，不另开文件：

```markdown
- T03｜卡点：不会构造辅助函数｜待测动作：只看题干说三步｜下次：11-11
```

## 折页记录

- 章末出完两份 PDF 后，在 `进度.md` 末尾追加「折页」小节，不另开文件。
- 记录本轮文件名与页数、笔记卡实收数、错题真错与空题数、未入册题号与原因。
- 容量数值统一见 07 顶部「容量参数」，此处只引用名称，不重复写数字。
- 折页数据卡字段见 07；本文件只管「写回哪里、写什么结果」。

## 掌握画像（交接层）

每章一份 `掌握画像.md`，与 `进度.md` 同级，路径见 `config.md`「产物清单」。它是**判断层**，不是账本：账本记发生了什么，画像记「现在什么水平、卡在哪、该怎么教」。两者冲突时以 `进度.md` 为准，画像随即修正。

固定七节，顺序不改：

1. **一句话交接**——三句内说清当前状态、最要紧的缺口、下一步该做什么
2. **账面**——题量、已掌握、待复测、未开始、复发题，只放数字
3. **掌握地图**——维度 × 四档状态（口径同本文「四档状态机」），每行给题号依据
4. **病根**——编号、触发信号、实际动作、应做动作、为什么是病根；按动作聚类，不按题号罗列
5. **有效与无效的教法**——只写有记录支撑的；无效项须注明据哪次记录
6. **接手须知**——第一步做什么、禁止做什么、判定口径
7. **证据索引**——指向 `进度.md` 小节、错题本、复检卷、折页、计划文件

写法约束：

- 不复述错题清单，只写结论与依据；不写百分比掌握度；无证据的推断不写
- 病根跨章复现时，章内标注「跨章」，并在篇级总览归并（如 `<math_root>\00_掌握画像_总览.md`）

写入时机：

- **首次**：本章首轮完整批改、错题本落盘后生成
- **更新**：每轮复检或复测结果回填 `进度.md` 后，只改「一句话交接」与「账面」（含数据时点）；病根、教法有新证据才改
- **不更新**：单题对错、单次讲解后

同时满足两条才算接得上：`进度.md` 标题下有一行指针指向画像；画像「账面」与 `进度.md` 的错题索引不矛盾。

## 长期记录

保存长期记录时注明日期、教师课程进度和教材版本，便于后续定位；掌握判断不使用无依据的百分比。

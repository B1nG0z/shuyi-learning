# shuyi-learning ｜数一笔记

考研数学一的 AI 伴学 Skill。以你指定的教师课程为主线，把「预习 → 跟课 → 带做 → 独立练习 → 诊断 → 复盘」跑成一条闭环，并把过程落成可打印的 A5 折页和能长期追踪的进度记录。

标准 Agent Skill 结构：`SKILL.md` + YAML frontmatter + 按需加载的 `references/`。纯 Markdown 驱动，不连任何外部服务，不往云端传学习资料。

## 适合谁

- 正在跟某位老师的考研数学一课程，想要「按课的顺序学」，而不是另起一套讲义的人。
- 需要有人陪着拆题、判错型、给补救练习，并且把错题留成以后能打印复习的东西的人。
- 想把学习进度存在自己硬盘上、随时换机器也不丢的人。

**不适合**：想要题库搬运、课程视频下载、一键对答案的人。本仓库不含任何课程、教材或题目内容。

## 工作方式

主流程固定一条，一次只推进一个环节：

```
定位 → 简讲 → 带做 → 独立作答 → 按表现处理 → 写回进度
```

11 个功能模块，命中路由才加载，不预读无关内容：

| 场景 | 模块 |
|---|---|
| 新章、知识点讲解、例题带做、独立练习、阶段复习 | `references/01-teaching.md` |
| 批改、看过程、错题照片、卡住、没思路 | `references/02-grading.md` |
| 讲题、首讲（章内 HTML） | `references/03-problem-page.md` |
| 页内提问、问答历史 | `references/04-qa-log.md` |
| 进度读写、掌握判定、掌握画像 | `references/05-progress.md` |
| 排计划、每日任务、集中刷题 | `references/06-planning.md` |
| 章末整理、打印、出折页 | `references/07-handout.md` |
| 折页排版、字体字号、PDF 规格 | `references/08-layout.md` |
| 数形结合、画图、函数图像 | `references/09-plotting.md` |
| 改卷、整卷批改、整章复测 | `references/10-assessment.md` |
| 复检、查漏、结算 | `references/11-recheck.md` |

产物刻意收敛成五类：章内一份错题本 HTML、章末两份 A5 折页 PDF（笔记 / 错题）、每章一份 `进度.md`、章内复检卷、每章一份 `掌握画像.md`。

## 安装

放到 harness 加载 Skill 的目录里就行，目录名保持 `shuyi-learning`（要与 `SKILL.md` 里的 `name` 一致）。

```bash
# 把 <skills-dir> 换成你的 harness 的 skills 目录
git clone https://github.com/B1nG0z/shuyi-learning.git <skills-dir>/shuyi-learning
```

不想用 git 的话，下载仓库 ZIP 解压到 `<skills-dir>/shuyi-learning/` 也一样。装完重载客户端或重启会话，确认技能已经加载。

不同 harness 的 skills 目录不一样（用户级目录下的 `skills/` 是最常见的一种），具体路径以你所用客户端的文档为准。卸载就是删掉这个目录，不会留下别的东西。

## 配置：只需要一个路径

首先要改的是 `config.md` 顶部的 `paths`。仓库里给的是示例值（`站点`、`折页` 这类相对路径），不改也能跑；但最好按你自己的习惯挑一个学习资料目录，四项都对着它写。

推荐的用法是：挑一个目录专门放学习资料，让 harness 的工作区开在这个目录里，`paths` 写成相对路径。这样目录叫什么都不重要，换机器、换盘符、换系统都不用重配。

```
<学习资料目录>\          ← 你自己选，harness 工作区开在这里
├── 站点\               ← 错题本、进度、复检卷
│   └── 数一\
└── 折页\               ← 打印件，刻意放在站点之外
```

```yaml
paths:
  site_root: "站点"
  math_root: "站点/数一"
  url_base: ""          # 可选，见下
  packet_root: "折页"
```

如果更习惯绝对路径，就把前两项和 `packet_root` 换成你机器上的完整路径（Windows 下用正斜杠最省事，如 `<盘符>/<你的目录>/站点`），效果一样。子目录名也可以随你的习惯改，只要四个值彼此对得上。

| 字段 | 含义 |
|---|---|
| `site_root` | 站点的根：章节目录、错题本 HTML 都在它下面 |
| `math_root` | 各篇章目录的上级，章节按「篇 / 序号_章名」两层排布 |
| `url_base` | 可选。用本地静态服务器打开错题本时填服务器地址；不想开服务器就留空，交付时改为给本地文件路径 |
| `packet_root` | 折页工作区。打印件不进站点，所以放在 `site_root` 之外 |

同一份 `config.md` 里还能改教师、课程、教材和练习册，仓库里的值同样是示例。改完不用动 `SKILL.md`。

学习资料本身（讲义、题库、扫描件、拍的照片）不要提交进本仓库，放在上面那个学习资料目录里就好。

## 开始使用

在 harness 里把工作区指到学习资料目录，新建一个会话，直接说要做的事：

```
用 $shuyi-learning 从高数基础篇第 3 章开始，先给我这章的章节地图
```

之后按需推进，常见说法都能对上路由：

- 「这题我拍给你，看看错在哪」→ 判错型、生成章内错题本
- 「这章怎么学」「先预习一下」→ 章节教学
- 「帮我排下周的计划」→ 学习计划
- 「这章学完了，出折页」→ 章末打印，生成两份 PDF
- 「复检一下」→ 按历史错题出闭卷卷

第一次用建议先把讲义或题库 PDF 放进对应章目录，或者按章上传照片，这样定位课时和题号有据可依。技能不会从课程链接推断没见过的内容。

## 目录结构

```
shuyi-learning/
├── SKILL.md                  入口：主流程、路由表、全局不变量、输出标准
├── config.md                 板级配置：教师、教材、目标、产物路径
├── SPEC.md                   维护规范：结构约定、规则归属、增删改流程、校验清单
├── agents/openai.yaml        界面元数据（显示名、简介、默认提示）
├── quick_validate.py         结构自检脚本
├── references/01..11-*.md    功能模块，每个模块自带接口头（输入 / 输出 / 依赖 / 不负责）
└── assets/                   输出骨架，不承载规则
    ├── explain-template.html    错题本页面模板（KaTeX 内联，离线可用）
    ├── gen-recheck.mjs          复检卷生成器
    ├── recheck.css              复检卷样式
    └── recheck.client.js        复检卷交互
```

## 依赖

- 日常使用不需要网络：错题本模板里的 KaTeX 和字体已内联打包，断网照样能开。
- 生成复检卷需要 Node.js 18 或更高版本（`assets/gen-recheck.mjs`）。
- 出折页 PDF 要本机能跑 Chrome/Chromium（用 `--print-to-pdf`），并且系统里装了宋体、黑体、仿宋三种中文字体：Windows 自带，macOS 和 Linux 常缺；缺字体会停下报错，不会拿相近字体顶替。
- 绘图请求默认输出可直接粘贴的 GeoGebra 命令，不依赖本地绘图库。
- 只有跑 `python quick_validate.py` 自检时才需要 Python 3。

## 维护与二次开发

`SPEC.md` 是这个技能自己的工程规范：单一 owner 原则、模块接口头、增删改流程、校验清单。改之前先读它。

规矩很简单：框架层规则只写在 `SKILL.md`，一类任务的全部规则只写在对应模块，新增功能先在路由表加一行、再在 `SPEC.md` 登记 owner。改完跑一遍 `python quick_validate.py`，它会检查路由、接口头、字数上限和 LICENSE。

## 说明

- 本仓库不附带任何课程视频、教材扫描件或题库。课程和教材在 `config.md` 里只是默认示例。
- 技能坚持「不虚构」：课程章节、课时、题目、页码只在资料可见或你提供时描述；没讲过的方法和自编题统一标「AI 补充」。
- 错题本顶栏的返回方块连的是同站点的入口页（模板里写的是 `../../00_数学看板.html`）。没有这个页面就把它删掉或改成你的入口地址，不影响题目内容和其他功能。
- 一章学完会做一次清理，只留错题本 HTML、两份折页 PDF、`进度.md`、`掌握画像.md` 和复检目录；折页的 HTML 源稿、`img\`、`.tmp\` 等中间产物会删掉。删之前会先列出清单，你自己的原始资料和照片一律不动。
